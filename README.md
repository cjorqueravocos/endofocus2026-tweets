# EndoFocus 2026 — Panel de Tweets

Panel de publicación en vivo para la cobertura de EndoFocus 2026 en X (Twitter).

## 📋 Acceso al panel

https://cjorqueravocos.github.io/endofocus-tweets/endofocus2026-panel.html

## ¿Cómo usarlo?

1. Abrí el link en el navegador (Chrome o Safari)
2. Seleccioná el día correspondiente — Día 1 o Día 2
3. Cuando llegue el momento de cada bloque, hacé clic en **"Publicar en X →"**
4. Se abre X con el tweet listo — solo presionás publicar
5. Marcá el tweet como publicado con **"✓ Marcar publicado"**
